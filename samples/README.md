## 데모 설정값

- 수수료 허용 비율: 0.5% (기본값)
- 비매출 입금 적요 키워드: `이자` (이 데모에서 쓰는 값. 실제 목록은 은행마다 설정 파일에서 정함)
- 건너뛸 행 키워드: `합계` (날짜를 읽을 수 없는 행에만 적용. 키워드가 없는데 날짜를 못 읽는 행이 있으면 처리를 멈춤)
