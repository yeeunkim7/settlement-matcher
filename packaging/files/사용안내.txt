정산 대사 사용 안내
====================

은행 거래내역과 매출 장부(CSV, XLSX)를 비교해
일치 / 불일치 / 검토 필요로 나눈 결과 엑셀을 만들어 드리는 프로그램입니다.
이 PC 안에서만 실행되고, 올린 파일은 어디에도 저장하지 않습니다.
Java를 따로 설치할 필요가 없습니다. (실행 환경이 runtime 폴더에 들어 있습니다)


1. 실행하기
-----------
  1) 압축 파일을 마우스 오른쪽 버튼으로 눌러 [압축 풀기]로 모든 파일을 풉니다.
     압축 파일 안에서 바로 실행하면 동작하지 않습니다.
  2) 압축을 푼 폴더에서 '실행.bat'을 두 번 누릅니다.
  3) 검은 창이 뜨고, 잠시 뒤 브라우저가 자동으로 열립니다.
     열리지 않으면 브라우저 주소창에 http://127.0.0.1:8080 을 입력합니다.
  4) 은행 거래내역과 매출 장부를 올리고 [대사 시작하기]를 누릅니다.
  5) 화면에서 결과를 확인하고 [결과 엑셀 받기]로 저장합니다.

  처음 실행할 때 "보안 경고" 창이 뜨면 [실행]을, "Windows의 PC 보호" 창이 뜨면
  [추가 정보] → [실행]을 누릅니다. (인터넷이나 메일로 받은 파일이라 뜨는 확인 창입니다)
  방화벽 허용 창이 뜨면 [취소]를 눌러도 됩니다. 이 PC 안에서만 쓰기 때문입니다.


2. 끝내기
---------
  검은 창을 닫으면 프로그램이 종료됩니다.
  쓰는 동안에는 검은 창을 닫지 마세요.


3. 설정 바꾸기 (application.yml)
-------------------------------
  같은 폴더의 application.yml을 메모장으로 열어 값을 바꾸고 저장한 뒤 다시 실행합니다.
  항목마다 설명이 적혀 있습니다. 자주 바꾸는 값은 다음과 같습니다.

  - server.port                         접속 포트 (기본 8080)
  - matcher.date-tolerance-days         날짜 허용 범위 ±일 (기본 1)
  - matcher.fee-tolerance-rate          입금이 적을 때 허용하는 차이 비율 (기본 0.005 = 0.5%)
  - matcher.bank-columns / ledger-columns   파일의 열 이름 (은행이나 장부 양식이 바뀌면 여기를 고침)
  - app.open-browser                    실행할 때 브라우저 자동 열기 (true / false)

  들여쓰기(앞쪽 공백)는 지우거나 바꾸지 마세요. 탭 대신 공백을 써야 합니다.


4. 문제가 생겼을 때
-------------------
  ● "8080 포트를 다른 프로그램이 쓰고 있어서 시작하지 못했어요"
    application.yml의 server.port를 8081처럼 다른 숫자로 바꾸고 다시 실행합니다.

  ● "정산 대사가 이미 실행 중이에요"
    이미 켜져 있는 상태입니다. 열린 브라우저 화면을 그대로 쓰면 됩니다.

  ● "runtime\bin\java.exe not found"
    압축을 일부만 풀었거나 압축 파일 안에서 실행한 경우입니다. 1번처럼 모두 풀고 다시 실행합니다.

  ● "파일을 처리하지 못했어요"
    화면에 나온 이유를 확인합니다. 열 이름이 다르면 application.yml의 열 이름을 파일에 맞춥니다.


결과 엑셀은 사람이 확인하기 위한 자료이며, 장부를 자동으로 확정하지 않습니다.
